## Cases and layers

The normative case matrix is `DOGFOOD-ORACLE.json`. It covers discovery; Hub-off/one-shot lifecycle; exact/vague Pull acquisition; Ledger exact resolution; code/document/Cortex composition; edit convergence and recovery; diagnostics; Push fidelity/recovery; grants and publication fence; Cortex lifecycle; Adapt observations; cross-repository budgeting; adapter parity; and bounded resilience.

Evidence layers are never conflated:

1. **Oracle/harness self-check** validates the independent comparator only.
2. **JavaScript adapter execution** validates a retained adapter/component, not native runtime.
3. **Native public boundary** requires a revision-compatible prebuilt artifact and isolated supported launch.
4. **Simulated host capture** proves only the captured envelope.
5. **Installed host/platform** requires installer-owned current-root identity and isolated qualification; it is not run in this cloud audit.

Each case is `PASS`, `FAIL`, `BLOCKED`, `NOT_RUN`, or `NOT_APPLICABLE`. Required blocked native cases prevent a full-product pass.

## Oracle rules

* Required facts are matched by independently authored exact strings/digests and source relationships, never product rankers or digest helpers.
* Valid alternative packets may pass if all required facts, identities, coverage, and omissions hold; top-K ordering is not overspecified.
* A typed failure passes only where explicitly permitted and only for the applicable safety/degradation assertion; it cannot establish positive readiness.
* Duplicate bodies/provenance never count as independent support.
* Exact recovery compares independently hashed original bytes and selector ranges.
* Unknown counters, host use, or evaluator identity remain unknown—not zero, successful, or effective.
* No oracle expectation may be edited after observation. Corrections require a versioned amendment retaining this frozen file and citing a normative source.
