MEMBRANE ICON PACK
==================

Source artwork
--------------
Master generated artwork: 1254 x 1254 px.
The pack includes an original raster master and a transparent-corner production master.

Windows
-------
- Windows/Membrane.ico: multi-resolution application icon (16 through 256 px).
- Windows/PNG/: individual PNG sizes from 16 to 512 px.
- Windows/Manifest-Assets/: common packaged-app / manifest logo sizes.

For a normal Win32/Tauri/Electron desktop app, Membrane.ico is the primary Windows icon.

macOS
-----
- macOS/Membrane.icns: application icon container.
- macOS/Membrane.iconset/: standard 16/32/128/256/512 + Retina PNG representations.
- macOS/Assets.xcassets/AppIcon.appiconset/: Xcode-ready macOS AppIcon asset catalog.
- macOS/Membrane-1024.png: 1024 px source for modern asset workflows.

Drop-in
-------
Contains commonly expected desktop-app icon filenames:
- 32x32.png
- 128x128.png
- 128x128@2x.png
- icon.ico
- icon.icns
- icon.png

Notes
-----
- PNGs and icon containers preserve transparent corners outside the rounded app tile.
- This pack is raster-derived from the generated artwork; it is not a vector/SVG reconstruction.
- The small sizes use mild sharpening after downsampling for better legibility.
