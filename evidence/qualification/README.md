# Qualification evidence

Store immutable `orthic.membrane.client-qualification.v1` wrappers here. Each must name one client & feature, carry all six client/model/host/provider/delivery/outcome pass gates plus an evidence digest, & embed a valid MBR-806 clean-VM platform receipt bound to current source. One client never qualifies another. Missing, stale, malformed, source-ready, or failed receipts render `unavailable`.
