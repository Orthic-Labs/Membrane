# Package managers

Blueprint publishes through supported Mac channels, all converging on immutable
GitHub Release assets and exact checksums generated by the workflow.

## Identities

| Channel | Identity |
|---|---|
| npm | `@membrane/blueprint` |
| Homebrew tap | `Membrane/homebrew-tap`, formula `blueprint` |
| MCP registry | `io.github.Membrane/blueprint` |
| Service ID | `io.membrane.blueprint` |
| Container | `ghcr.io/membrane/blueprint` |

## Rules

- Every URL references an immutable release asset (exact version), never
  `latest`.
- Every manifest hash is generated from the immutable release asset by script, never
  by hand.
- Homebrew installs the same portable archive plus completions/man page.
- Docker is documented for CI/headless use only.
- MCP registry metadata launches `blueprint mcp serve` from the published npm
  package.
- Publication runs only after release verification in protected
  environments; it may open downstream PRs but never rewrites an existing
  release.

## Validation

```sh
node --test tests/package-manager-manifests.test.mjs
ruby -c release/homebrew/blueprint.rb.template
node -e "JSON.parse(require('fs').readFileSync('server.json','utf8'))"
```
