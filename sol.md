Organization is strictly by observable capability or system mechanic; repositories never receive standalone chapters.

- **Not evidenced** means inspected source, manifest, config, tests, & primary README expose no implementation for that function. It does not claim no implementation exists outside this snapshot.
- **Framework/pluggable** means repo supplies interfaces or integrations but intentionally chooses no single backend.
- **Hosted boundary** means vendored repo contains clients/integrations while server internals are outside snapshot.
- **Resource floor** means smallest useful checked-in deployment, not vendor-hosted infrastructure hidden behind an API.
- Performance claims without checked-in measurement are described as design choices, not benchmark results.
- Claims describe inspected local state, not current upstream state; source links are the authority until a current corpus manifest is regenerated.
- Source, manifests, configuration, tests, migrations, tool registries, & packaging files are evidence. README material is used only for identity, declared positioning, or explicitly labeled claims.
- `SEM` & `STA` are included in every core row & all long-tail dimensions.

## Performance & optimization readout

Lowest infrastructure floors: CTE has no runtime; PRP is one zero-dependency pass; RTK is one streaming Rust binary; RG, CC, CRG, CM, AM, MEM, B0, CBM, & LCTX keep indexed work local without mandatory database services.

Strongest visible DB efficiency pattern is embedded SQLite-family storage + incremental/content-addressed updates + bounded retrieval. MGR, MCL, C8, & LET deliberately accept more processes, RAM, network hops, backups, & consistency work to gain shared concurrency, queues, isolation, & horizontal scale.

Largest ingest costs sit with GR, COG, M0, MCL, & MEMY because LLM extraction, embeddings, graph construction, or multi-store writes purchase richer later recall. Strongest work-avoidance designs sit with B0 content caches, CBM/RG/CC/CRG precomputed code graphs, SC/HDR content-addressed recovery, CM sandboxing, RTK model-free stream filters, & LCTX content-addressed spill.
