# Orthic Hub

This is the Orthic suite Hub, migrated from `membrane/apps/membrane-hub` with
git history preserved (source SHA `e6ae75dd16d53b001df7b7b3b4ca2c27c3cff4d6`).

The Hub launches; products serve.

See `docs/plans/orthic/SEAM-CONTRACT.md` in the main workspace repo for the
normative contract governing this repo's boundary with `cortex` and `membrane`.
