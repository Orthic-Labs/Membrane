Static mockup. HeardRight's frameless shell ported (no OS titlebar, sidebar fused into the chrome row); Membrane identity applied; flat colour only. Every state below is one the Hub can actually reach today, and the evidence strings are the typed reasons the snapshot emits.

Dashboard, running (Windows chrome)

The workspace signature is the admission ledger: subject, verdict, evidence, observed. One grammar for the whole app. The verdict is a shape plus a word, so it survives greyscale and colour-vision deficiency, and the evidence column prints the typed reason verbatim rather than a friendly paraphrase.
