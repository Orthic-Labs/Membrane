# Installation

Canonical index for Membrane install, bootstrap, activation, & removal. Product documentation
lives in this directory; package artifacts reference these paths through generated release metadata.

- [install.md](install.md) — native install contract & tray-owned runtime lifecycle
- [npm.md](npm.md) — `@membrane/membrane` npm bootstrap loader
- [oci.md](oci.md) — optional headless Docker/OCI image
- [registry.md](registry.md) — MCP Registry metadata (MBR-907)
- [contract.md](contract.md) — installation manifest and IPC handshake contract (MBR-105)
- [roots.md](roots.md) — the four durable Membrane Stable Roots directories (MBR-106)
- [uninstall.md](uninstall.md) — receipt-bound removal contract (MBR-205)
