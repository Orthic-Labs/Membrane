## CHANGES

All edits are inside owned lane files. No runner/host module was modified.

1. `engine/crates/membrane-runtime/src/bin/membrane-daemon.rs`
   - `DaemonBackgroundExecutor::tick` now takes `control: &LifecycleControl`; both call sites updated (post-ready tick ~line 449; loop tick ~line 496).
   - Lapsed-request guard before admission: `snapshot.deadline_unix_ms <= now` → `observe_deferred(TimeGate)` + return. Previously a persistent stale snapshot was admitted every 250 ms — burning an attempt and reserving `input_tokens` against per-turn/aggregate budgets — before the provider could only refuse TimeGate; after `MAX_ATTEMPTS` the dead job-id hit `RetryLimit` forever while aggregate budget kept draining. Now it costs zero budget and emits one typed deferral.
   - Mid-tick authority revocation check after admission, before input load: `!control.background_authority_open()` → `set_hub_active(false)` → admitted job ends as `Cancelled/HubInactive`. Closes the window where a control-thread drain/parent-close could revoke the background permit while the tick proceeded to DB load + provider execution.
   - Request-lapse check after input load: `snapshot.deadline_unix_ms <= now` → `scheduler.cancel(job_id)` → typed `Cancelled` terminal. First production caller of `BackgroundReviewScheduler::cancel` (previously test-only).
   - New `mod tests` additions (3 tests, env-isolated via `TICK_ENV_LOCK` + `MEMBRANE_BACKGROUND_REVIEW_INPUT`): `lapsed_request_defers_time_gate_without_reserving_budget_or_attempt` (incl. dedup assertion), `revoked_authority_cancels_admitted_job_before_provider_execution`, `unchanged_input_failure_state_emits_one_deferral`.

2. `engine/crates/membrane-runtime/src/background_review.rs`
   - `SchedulerState::last_deferral: Option<(reason, job_id, kind)>` + dedup in `observe_locked_with_turn_tokens`: a `Deferred` observation identical to the most recent emitted deferral is suppressed; any non-deferred observation clears the marker so a later identical deferral records again. Single funnel point — every emission path (`start` deferrals, `observe_deferred`, `observe_idle`, producer refusals, constructor record) is covered. Preserves state transitions and all Started/Completed/Failed/Cancelled records; fixes the H5 rail drowning itself at 4 records/sec under any persistent gate.
   - New unit test `repeated_identical_deferrals_emit_once_until_state_changes`.

3. `engine/crates/membrane-runtime/src/background_review_input.rs` — unchanged this pass (producer verified correct: atomic publish, cursor continuity, no-activity no-op, host-measured token requirement).
