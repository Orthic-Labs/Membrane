# Support bundles

Create one bundle with `membrane cli doctor --bundle ./membrane-diagnostic.json`.
Attach the file unchanged with the Hub reason, observed time, evidence, resolver,
installation ID, and release generation. Redact credential-shaped values before
sharing; the supported bundle already excludes prompts, source bodies, rows,
token values, sample IDs, repair text, and local paths.

Repair boundary: support capture is read-only and does not prove provider,
adapter, signature, or liveness when its reader reports `unavailable`. Do not
attach ad-hoc database dumps or event logs containing user content.
