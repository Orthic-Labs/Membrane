ContextRight is a world-class desktop application that pairs a local SQLite-backed memory store with a Rust orchestration engine. It is designed for engineers who want durable, searchable session memory without sending their private transcripts to a third party. The application ships as a single binary that boots in under a second and exposes a small HTTP surface on loopback for the frontend to talk to. There is no cloud dependency, no telemetry, and no remote model call unless the user explicitly configures one.

The memory engine has three layers. The first is a structured recall store that indexes every recorded turn by content, by topic, and by recency. The second is a vector recall path powered by a small open-weight sentence embedder that runs locally through ONNX. The third is a curation layer that periodically consolidates related memories into higher-level summaries so the recall surface stays manageable as the corpus grows.

Beyond memory, the application also owns several deterministic context-engineering transforms. It can skeletonize source code into a tree-sitter-derived signature view that preserves structure without bodies. It can compress prose with a learned token-drop classifier that approximates LLMLingua-2. It can run a command and return a head-and-tail view of the output while preserving the child exit code and spilling the full transcript to a side file. All of these are exposed both as CLI verbs and as HTTP routes against the resident daemon.
